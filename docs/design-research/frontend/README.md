# СамоКеттик: исследование UI и выбранный вариант

Исследование относится к U012. Исходные наблюдения, HTTP statuses и computed styles сохранены в [references.json](references.json); timestamps получены при реальном открытии. [font-check.json](font-check.json) содержит SHA-256 фактических TTF и результат cmap для Ңң, Өө, Үү. Шрифты распространяются с OFL, лицензии рядом с файлами и в frontend public/fonts.

## Опубликованные аналоги

- [Whoosh](https://whoosh-bike.ru/): browser HTTP200, после загрузки анимаций просмотрен скриншот reference-whoosh.png. Верхняя навигация компактная, типографика Nekst; брендовый жёлтый используется для одного главного действия и логотипа, остальное поле нейтральное. Фото телефона показывает приоритет карты с маркерами. Маркетинговый крупный логотип и фотоколлаж не подходят рабочему экрану аренды. Не копируем жёлтую бренд-палитру/коммерческий шрифт.
- [Bolt scooters](https://bolt.eu/en/scooters/): browser HTTP200, просмотрен reference-bolt.png. Computed typography Inter, H1 72px/750 на маркетинговой странице; тёмный текст rgb(25,31,28), светлое поле, зелёный CTA. Кнопки и предметные фотографии функциональны, карточки не являются основой всей страницы. Для приложения берём иерархию одного основного действия и спокойные поверхности, а не маркетинговый масштаб заголовков/собственные фотографии Bolt.
- [Lime how-to](https://www.li.me/how-to-ride): текст официальной страницы прочитан через web, но браузер получил **403 security verification**. reference-lime.png показывает блокировку, его нельзя использовать как доказательство внешнего вида Lime. Из текста подтверждён сценарий map → reserve/select → start; визуальные/типографические выводы по нему не делались. Ограничения и тарифы Lime в проект не переносятся.

HEX вариантов — наши проектные цвета, не утверждение официальных брендбук-значений аналогов. Исследованы реальные опубликованные сервисы; чужие иллюстрации, шрифты и готовые приложения не копируются. SVG самоката/иконки написаны для проекта.

## Самостоятельные варианты

Исходники макетов: preview.html/js и разделённые SCSS modules. Карта/30 маркеров/геозона читаются из настоящего API; команды аренды отключены, пример поездки/строк истории обозначен макетом. Макеты не являются реализованным приложением. Сборка prototype CSS из Sass выполнялась локальным helper, сгенерированный CSS не является авторским source.

| Вариант | Композиция | Роли цветов / типографика |
| --- | --- | --- |
| Карта | Полноэкранная карта, компактная плавающая карточка; на mobile нижняя панель | Нейтральная светлая карта/поверхность, терракотовое основное действие #ae4a30, угольный текст; Geologica wordmark и Golos Text для данных |
| Список | Постоянная боковая колонка выбора/фильтра, карта справа; на mobile карта над списком | Холодное белое поле, синий #355a9d для выбранной строки и CTA; Golos Text, меньше иллюстраций и плотнее данные |
| Поездка | Ограниченная карта, независимая правая панель суммы/управления, строки истории ниже | Тёмная зелёная шапка #19413e, бумажное поле #f4f1e9; Geologica, крупная стоимость и разделители вместо набора карточек |

Все три проверены в Chromium на 1440×1000 и 430×980: 30 markers, GeoJSON, реальные OSM tiles, без pageerror/горизонтального overflow. Фактический результат — [preview-check.json](preview-check.json). Скриншоты и preview были открыты пользователю до изменения рабочего UI.

Пользователь выбрал **«Карта — большая карта и плавающая карточка»**: [точный ответ U013](../../prompts/013-frontend-direction.md). После этого начата реализация React, не требуется повторного согласования той же композиции. Состояния аренды/ошибки используют ту же визуальную систему. Цена/геозона/состояния в рабочем UI берутся из backend; статические цифры макета поездки в app не переносятся.

Для воспроизведения макетов из корня checkout после npm ci и запуска основного Compose: `node docs/design-research/frontend/serve-preview.mjs`. Helper компилирует SCSS в ignored outputs/frontend-directions и обслуживает http://127.0.0.1:5174/. Это отдельное read-only preview, не маршрут рабочего UI; после просмотра завершите процесс. Скриншоты direction-*.png сохранены рядом с этим документом как результат выбора.
