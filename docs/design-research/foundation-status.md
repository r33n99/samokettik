# Техническая страница подключения: минимальный референсный разбор

Это временная страница E1 для доказательства frontend → API → PostgreSQL. Она не заменяет будущее исследование UI аренды, несколько визуальных вариантов и выбор пользователя.

Изученный опубликованный аналог: [Supabase Status](https://status.supabase.com/). Полезное конкретное решение: состояние системы выражено прямым текстом, а компоненты/подсистемы отделены от общего состояния; пользователь может понять, что именно доступно. Для трёх компонентов локального стенда сложная региональная сетка и история инцидентов не нужны. Доступность `https://status.openstreetmap.org` через web tool подтвердить не удалось; этот адрес не считается изученным референсом.

Принятый минимальный объём: название, город, один результат проверки, фактическое число самокатов, timezone/currency и кнопка повторного запроса. Нет карты/маркетингового hero/декоративной нумерации/псевдодоступных действий аренды. Цветовая точка дополняет текст; не является единственным носителем состояния. Светлая нейтральная поверхность и тёмный текст — собственный выбор для временного стенда, не заявляются брендбуком Supabase.

Используется системный шрифт без загрузки коммерческих файлов. Продуктовые RU/KY-шрифты и actual glyph coverage будут проверяться на этапе интерфейса. Текущая страница русская; полноценная локализация не заявляется выполненной.
