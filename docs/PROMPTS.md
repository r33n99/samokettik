## Проверяемые обращения к инструментам на E0

Это не новые пользовательские промпты, а описание фактически выполненных запросов; воспроизводимые команды перечислены в WORKLOG.md:

- Локальный аудит cwd, файлов, Git-корня и Git-идентичности, команд и версий Node/npm/Docker.
- Чтение двух SKILL.md и выбранных PostgreSQL-rules; чтение пользовательской библиотеки design references без изменения её содержимого.
- Проверка официальных документов PostgreSQL, Drizzle, Fastify, Node, Tailwind, Google, OSM и Resend; источники сохранены в SOURCES.md.
- Создание Markdown-документов, затем проверка ссылок, наличия требований и отсутствия app-кода. Фактический результат проверки добавляется в WORKLOG.md только после запуска.

LLM-промпты для генерации изображений, дизайна, SQL или функционального кода на этом этапе не выполнялись.
