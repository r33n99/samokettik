# Распределение демонстрационного транспорта

`config/demo.json → seedLocations` содержит 30 уникальных координат E7: по одной на каждый SK-001…SK-030. Они распределены по всей сохранённой зоне Бишкека, включая все четыре компонента MultiPolygon. Охват точек: 0,2750359° широты и 0,2505226° долготы (примерно 30 × 20 км). Зона включает отдельные удалённые участки, поэтому это шире центральной части города.

Точки подготовлены детерминированно: внутренние центры ячеек сетки 18 × 18 для каждого компонента полигона; сначала ближайшая к центру внутренняя точка каждого компонента, затем точки с максимальным расстоянием до уже выбранных, с поправкой долготы на широту. Итоговые координаты сохранены явно для проверки и редактирования. Это искусственные демонстрационные позиции, а не подтверждённые парковки или привязка к дорожной сети. Сервер при загрузке проверяет количество, уникальность и принадлежность каждой точки геозоне.

Новая БД получает координаты обычным `npm run db:seed`. Повторный seed сохраняет существующие данные. Для уже наполненной локальной демонстрационной БД выполните отдельно:

```sh
npm run demo:redistribute
```

Нужен `DEMO_SEED_ENABLED=true`. Команда использует существующий `.env`, не принимает секретов в аргументах. Обновляются только координаты существующих демонстрационных ID с соответствующим publicCode. Заряд, режим обслуживания, пользователи, аренды, счета и платежи сохраняются. Все изменения — одна транзакция; строки транспорта блокируются по ID. Активная аренда проверяется отдельным SQL-запросом после получения блокировок, поэтому видна бронь, которая успела завершить commit во время ожидания. Транспорт в состояниях reserved/riding/paused пропускается; повторный запуск без изменений не повышает version. При конкурирующей долгой операции timeout откатывает всю команду, её можно повторить позже.

Обновления увеличивают vehicle.version и запускают существующий PostgreSQL NOTIFY/WS механизм. Если самокат занят, его можно перераспределить отдельным повтором команды после завершения аренды. Автоматического переноса во время работы, нового production API или изменения применённых миграций нет.

После изменения config для Compose пересоберите API и worker с одинаковым config hash:

```sh
npm run compose:up
```

На карте кнопка обзора транспорта показывает весь текущий fleet, а выбор самоката приближает его. Проверки: `tests/unit/demo-locations.test.ts`, PostgreSQL tests foundation/trips и реальная карта desktop/mobile.
