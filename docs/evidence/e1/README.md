# Доказательства технического этапа E1

`checks.json` содержит реальные команды, время начала/окончания, exit codes и SHA-256 исходных логов. `logs/` сохраняет полные результаты, включая ошибки первого typecheck, npm audit и неудачного restart smoke. Времена не реконструированы: их записывал `scripts/check.mjs` при запуске.

`helpers/` — сохранённые точные исходники двух одноразовых проверок, выполненных из `work/`. Чтобы воспроизвести их, скопируйте файлы обратно в `work/` и запускайте из корня проекта. `check-restart.mjs` останавливает **PostgreSQL текущего Compose-проекта**, затем восстанавливает его; не запускайте во время важной работы. Этот helper исправлен после неподдерживаемого `start --wait`; прежний ошибочный результат сохранён в логе.

Основные поддерживаемые проверки доступны штатно: `npm test`, `npm run test:db`, `npm run test:e2e`. Успешный E2E использовал настоящий backend/БД; UI error/retry проверялся отдельно с подменой readiness-response.

Секретный `.env` в доказательства не включён; перед экспортом проверялось отсутствие фактического локального пароля. Наличие raw-логов в Git разрешено точным исключением только для `docs/evidence/`; обычные runtime-логи остаются игнорируемыми.
