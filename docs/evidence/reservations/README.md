# Серверное бронирование — фактические проверки

checks.json содержит команды, реальные ISO timestamps, exit codes и SHA-256 raw logs. Сохранены и неуспешные прогоны. Секреты локального env проверены на отсутствие в логах. Тесты и live demo воспроизводятся штатными npm scripts; конфигурация 4/2 s используется только изолированным restart integration test. Стандартный API сохраняет deadlines 900/180 s.
